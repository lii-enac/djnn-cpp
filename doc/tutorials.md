# Examples & Tutorials

## Examples

Take a look at `djnn` and `smala` examples:

- [Hello world](https://smala.io/hello.html) with an empty `Frame` with exit button
- [Control structures](https://smala.io/controlling.html) with an example of the main components that make up the smala language:
  - `Binding`: an activation link between a source and a destination
  - `Connector`: a data-flow component that copies the value of a source property to a destination property each time the value of the source is set
  - `Assignment`: copies the value of a source property to a destination property but only one time, on activation
  - `Switch`: only one of its children can be active at a time
  - Finite State Machine `FSM`: works in a very usual way, that is by specifying states and transition
  - Combining `Switch` and `FSM`
- [Drawing shapes](https://smala.io/drawing.html) with an example of how to draw a `Rectangle` and a `Polygon`
- [Custom component](https://smala.io/custom.html) with an example of how to define a custom component (ex: your own button)
- [SVG](https://smala.io/svg.html) with an example of using a SVG file to make drawing easier

## Tutorials

Take a look at the 7 tutorials [readme](https://github.com/lii-enac/smala/blob/master/cookbook/gui/7GUIs/readme.md) and [code](https://github.com/lii-enac/smala/tree/master/cookbook/gui/7GUIs) to learn `djnn` and `smala` programming step by step.

This is the [smala](https://github.com/lii-enac/smala) version of the `7GUIs` [GUI Programming Benchmark](https://eugenkiss.github.io/7guis/) with a gradually increasing level of difficulty.
